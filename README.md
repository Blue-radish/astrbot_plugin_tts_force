# 说一句就念给你听 · astrbot_plugin_tts_force

把「这句话用语音说」交给模型，插件只负责**可靠地发出去**。

插件只提供一个工具：

```
send_voice(text)   →   合成音频，作为独立一条消息发给用户
```

模型可以先用文字说一句，再调用它补一段语音；可以判断这次该念还是该写。插件不猜、不掷骰子、不改写回复。

> **和 AstrBot 自带 TTS 的关系**
> 请把 AstrBot 自带的 TTS 关掉（`provider_tts_settings.enable = false`），否则宿主会先念一遍，变成两遍。
> 语音由 AstrBot 的 TTS 提供商合成，本插件负责「念什么、念得成不成」。

## 安装

1. 把本目录放进 AstrBot 的 `data/plugins/astrbot_plugin_tts_force/`
2. 在「提供商」页配好一个 TTS 提供商（`text_to_speech` 类型）
3. 关掉 AstrBot 自带的 TTS
4. 重启 AstrBot，插件配置里「语音提供商」留空＝跟随当前会话，或指定一个
5. 私聊机器人发 `/语音测试`，确认能真的收到一条语音

## 模型看到什么

工具说明里写清了三件事，这就是全部的「策略」：

| 场景 | 引导 |
|---|---|
| 生活闲聊、早晚问候、道谢道歉、情绪表达、哄人、叫对方休息、一句短回应 | 适合语音 |
| 技术讨论、长篇解释、代码、命令、路径、链接、清单、数字、需要复制回看的内容 | 用文字 |
| 用户明确要求「念给我听」「用语音说」「语音回我」 | 一定要调用 |

另外要求模型：一次只发一句、口语、不带 markdown/表情/代码/括号动作。

## 工具返回什么

| 情况 | 返回给模型 | 用户收到 |
|---|---|---|
| 成功 | 「语音已经发出去了，别再把同一句用文字重复」 | 一条语音消息 |
| 超过字数上限 | 「这段 63 字，超过上限 50 字，请缩短再调」 | 什么都没有（不截断句子） |
| 上一条还在合成 | 「还在合成，稍等或先用文字」 | 什么都没有 |
| 提供商/网络/鉴权问题 | 分类 + 脱敏后的具体原因 | 什么都没有 |
| 音频文件不可用 | 「收到文件但用不了：不是可解析的 WAV」 | 什么都没有 |
| 配置的提供商不存在 | 成功结果里附带「已回退到会话默认，可提醒用户检查配置」 | 一条语音消息 |
| 发送本身失败 | 「语音没有发出去：原因」 | 什么都没有 |

**任何一个失败都不会抛异常给模型框架**，都会变成一句能让模型继续决策的话。失败时文字回复由模型自己写——因为只有它知道原本想说什么。

## 三项设置

| 键 | 默认 | 说明 |
|---|---|---|
| `provider_id` | `""` | 留空＝跟随当前会话；也可以选一个指定提供商 |
| `max_chars` | `50` | 单次语音字数上限，超过就拒绝并回给模型实际长度。句子不会被截断 |
| `timeout` | `300` | 单次合成等待上限（秒），超时如实告诉模型 |

外加两个排障/开关项：`enable`（总开关）、`test_text`（`/语音测试` 念的那句话，最多 200 字）。

字数为什么是 50：自建 qwen3-tts 实测约 **0.5 秒/字**，50 字≈25–30 秒合成，300 秒超时留了十倍余量。你的 TTS 更快就可以调大。

## `/语音测试`

绕开模型直接合成一句固定话发给你，用来**隔离故障**：

- 收到了语音 → 提供商和插件都正常，问题在模型没有调用工具（去调工具说明或换模型）
- 报「鉴权失败/连不上/超时/收到文件但用不了」 → 是 TTS 服务或配置的问题

私聊谁都能用，群里只给管理员，受「同一会话不并发合成」约束。

## 并发与可靠性

- 同一会话同一时间只合成一条：会话位在第一个 `await` **之前**占住，两次并发调用不会各合成一遍
- 合成结果要过校验：文件存在、非空、扩展名是 wav 就必须能解析出音频帧
- 错误信息先脱敏再截断（`api_key=abc.def.ghi` → `api_key=***`），因为工具结果会回到模型上下文
- 每次合成写日志：字数、提供商、耗时、失败原因

## 从 2.x 升级

3.0 删掉了随机概率、语音标记、关键词识别、场景正则、长期偏好记忆和自动改写回复。
配置文件里这些旧键会在启动时**连值一起删掉**（`random_rate`、`voice_markers`、`auto_groups`、`strip_patterns` 等 18 个），
只保留 `enable`、`provider_id`、`max_chars`、`timeout`、`test_text`。

如果你之前靠「概率自动发语音」，升级后不再有主动语音，只有模型显式调用工具才会念——这是设计意图。
