# 说一声就念给你听 `astrbot_plugin_tts_force`

要不要把这一轮回复**说给对方听**，按对方的意愿和会话节奏来定，而不是纯掷骰子。

## 判断顺序

| 顺序 | 对方/模型的表达 | 结果 |
|---|---|---|
| 1 | 对方明确拒绝：「别发语音」「不用念了」 | 本会话进入**文字模式**，模型标记和随机都被挡住 |
| 2 | 对方说不方便听：「我在开会」「听不了」 | 同上，临时生效 |
| 3 | 对方点名：「这句念给我听」 | 本轮一定语音，放宽字数上限 |
| 4 | 对方想用语音聊：「接下来用语音」 | 本会话提高主动语音倾向（`voice_mode_rate`） |
| 5 | 咨询句：「发语音功能怎么设置」「voice 是什么意思」 | 当普通提问，**不**触发 |
| 6 | 模型主动：回复最前面写 `<语音>` | 走「系统主动语音」约束 |
| 7 | 随机：普通短回复掷骰子 | 走「系统主动语音」约束 |

对方点名 > 系统主动语音。旧的拒绝可以被新的点名覆盖——更新更明确的指令优先。

## 系统主动语音共享同一套约束

模型标记和随机**不是两套规则**，都要过这些闸：

1. **场合**：私聊总是可以；群里只认 `auto_groups` 白名单
2. **内容**：带链接、代码块、清单步骤、大段英文数字的不念（模型标记只放行超短句，随机要求至少 2 个实字）
3. **频率**：距上次主动语音至少 `auto_min_gap` 秒（模型标记也记进这个时间，不会紧跟着再来一条）
4. **长度**：超过 `max_chars` 发文字
5. **等待**：主动语音最多等 `auto_timeout` 秒，超时先发文字；对方点名的用 `timeout`

## 会话偏好

| 对方说法 | 偏好 | 有效期 |
|---|---|---|
| 「别发语音」「我在开会」「听不了」 | 文字 | `text_mode_ttl`（默认 30 分钟） |
| 「以后都用文字」 | 文字 | 长期（落盘 `prefs.json`） |
| 「接下来用语音」「语音聊」 | 语音优先 | `text_mode_ttl` |
| 「恢复默认」「随便你」 | 回到自动 | — |

偏好按会话（umo）隔离，临时偏好会自动过期，长期偏好重启后仍然有效。

## 合成前清洗

括号里的动作神态 `（她低下头）`、`【】` 注释、markdown 符号、代码块、`<system_reminder>` 都不会被念。
合成失败、超时、冷却中、上一条还在合成、对方说过不方便听——一律保留文字回复。

每次决定都写日志：发语音时标注来源（`对方点名` / `模型标记` / `随机`），没发时写明原因
（`对方说过「不方便听」` / `带链接，念出来是噪音` / `距上次主动语音才 30s` / `这次没掷中（15%）`）。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enable` | `true` | 总开关 |
| `provider_id` | `qwen3-tts` | TTS provider id；拿不到就退回当前会话默认 TTS |
| `voice_markers` | `<语音>` 等 7 种 | 模型表示「这条用语音」的标记 |
| `force_keywords` | 7 个较窄的词 | 对方点名要语音；**不要**放裸 `voice` |
| `inject_prompt` | `true` | 是否往系统提示词注入交流方式规则 |
| `prompt_hint` | `""` | 自定义提示词，支持 `{marker}` `{max_chars}` |
| `max_chars` | `50` | 主动语音字数上限 |
| `max_chars_user` | `2000` | 对方点名时的字数上限 |
| `auto_timeout` | `40` | 主动语音合成等待上限（秒） |
| `timeout` | `300` | 点名语音合成等待上限（秒） |
| `cooldown` | `0` | 任意两次语音之间的最小间隔（秒） |
| `random_rate` | `15` | 日常闲聊主动语音概率（0-100） |
| `voice_mode_rate` | `80` | 对方想用语音聊时的概率 |
| `auto_min_gap` | `600` | 两次主动语音之间的最小间隔（秒） |
| `auto_groups` | `[]` | 允许主动语音的群号，留空 = 只在私聊 |
| `text_mode_ttl` | `1800` | 临时文字/语音偏好的有效期（秒） |
| `strip_patterns` | 6 条正则 | 合成前删掉的内容 |
| `strip_markdown` | `true` | 顺带去掉 markdown 与代码块 |
