# 说一声就念给你听 · astrbot_plugin_tts_force

要不要把这一轮回复**说给对方听**，按对方的意愿和会话节奏来定，而不是纯掷骰子。

AstrBot 自带的 TTS 只有「每条都念」或「按概率念」两种。这个插件管的是**什么时候该用语音**：
谁在听、方不方便听、内容适不适合听、最近几轮是什么节奏。

> **和 AstrBot 自带 TTS 的关系**
> 本插件接管语音决策，所以请把 AstrBot 里的 TTS **关掉或概率设 0**
> （`provider_tts_settings.enable = false`），否则自带 TTS 会先念一遍，变成两套并存。
> 语音本身仍然由 AstrBot 的提供商合成，本插件只负责「念不念、念什么、什么时候念」。

## 安装

1. 把本目录放进 AstrBot 的 `data/plugins/astrbot_plugin_tts_force/`
2. 在 AstrBot 的「提供商」页面配好一个 TTS 提供商
   （`text_to_speech` 类型，例如 OpenAI 兼容的 `openai_tts_api`）
3. 关掉 AstrBot 自带的 TTS（见上）
4. 重启 AstrBot，在 WebUI 的插件配置里把「语音服务」选成你要的那个提供商
5. 私聊机器人发 `/语音测试`，确认能真的合成出音频

`/语音测试` 会把结果分成「鉴权失败 / 模型或音色无效 / 请求超时 / 连不上接口地址 /
返回的不是可用音频」，并给出耗时、格式、大小和时长；密钥在错误信息里会被遮掉。

## 判断顺序

| 顺序 | 对方/模型的表达 | 结果 |
|---|---|---|
| 1 | 明确拒绝：「别发语音」「不能用语音」「不用念了」 | 本会话进入**文字模式**，模型标记和随机都被挡住 |
| 2 | 说不方便听：「我在开会」「听不了」 | 同上，临时生效（「在开会」需要有「我」、且没被否定） |
| 3 | 点名：「这句念给我听」「用语音解释一下」 | 本轮一定语音，放宽字数上限 |
| 4 | 想用语音聊：「接下来用语音」 | 本会话提高主动语音倾向，间隔也缩短 |
| 5 | 咨询：「发语音功能怎么设置」「voice 是什么意思」 | 当普通提问，**不**触发 |
| 6 | 模型主动：回复最前面写 `<语音>` | 走「系统主动语音」约束 |
| 7 | 随机：普通短回复掷骰子 | 走「系统主动语音」约束 |

对方点名 > 系统主动语音；新的明确指令覆盖旧的拒绝（说过别发语音，之后点名仍然念）。
「随便」「都行」这类词必须指向交流方式（「语音文字都行」）才算恢复默认。

## 内容安全：念出来不能等于弄丢

**主动语音**遇到可复制信息——代码块、行内代码、链接、清单/步骤、长数字——直接不发语音，
整条留文字。

**对方点名**时照念，但**文字也一起留着**（文字 + 语音两条都发），因为他要听的可能是别的东西，
而命令只存在于文字里。

## 系统主动语音共享同一套约束

模型标记和随机不是两套规则，都要过这些闸：

1. **场合**：私聊总是可以；群里只认 `auto_groups` 白名单
2. **内容**：可复制信息不念；纯符号、「The quick brown fox」、一长串数字不念
3. **频率**：平时距上次主动语音至少 `auto_min_gap` 秒；语音模式用 `voice_mode_min_gap`
4. **长度**：超过 `max_chars` 发文字
5. **等待**：主动语音最多等 `auto_timeout` 秒，超时先发文字；对方点名的用 `timeout`
6. **总开关**：`auto_enable` 关掉后，标记和随机都不再发语音，只保留对方点名

## 会话偏好

| 对方说法 | 偏好 | 有效期 |
|---|---|---|
| 「别发语音」「我在开会」「听不了」 | 文字 | `text_mode_ttl`（默认 30 分钟） |
| 「以后都用文字」 | 文字 | 长期（落盘 `prefs.json`） |
| 「接下来用语音」「语音聊」 | 语音优先 | `text_mode_ttl` |
| 「语音文字都行」「恢复默认」 | 回到自动 | — |

偏好按会话隔离；**群里按发言人分开记**——一个人在群里说不方便听，不会让整个群静音。
群级是否允许主动语音由 `auto_groups` 决定。

## 合成期间对方改主意

偏好带版本号，每条语音任务记下开始时的版本和轮次。合成结束时再复核：

- 对方在这期间说了「别发语音」→ 这条语音**丢弃**，只发文字
- 对方已经继续说下一句了 → 旧语音**不再补发**，避免新文字先到、旧语音后到
- 对方点名要的那条不受「旧的文字偏好」影响（明确指令优先）

## 合成前清洗

括号里的动作神态 `（她低下头）`、`【】` 注释、markdown 符号、代码块、`<system_reminder>` 都不会被念。
合成失败、超时、冷却中、上一条还在合成、对方说过不方便听——一律保留文字回复。

每次决定都写日志：发语音时标注来源（`对方点名` / `模型标记` / `随机`）和提供商，
没发时写明原因（`对方说过「不方便听」` / `回复含代码块，主动语音跳过` / `距上次主动语音才 30s`
/ `这次没掷中（15%）` / `丢弃这条语音：对方在这期间改了交流偏好`）。

## 「点名一定念」的边界

这句话有前提，别当承诺：字数超过 `max_chars_user`（默认 2000）、
冷却中（`cooldown`）、上一条还在合成、没拿到可用提供商、合成失败或超时——
这些情况下仍然只发文字，日志会说明是哪一条。

## 配置

**语音服务**

| 键 | 默认 | 说明 |
|---|---|---|
| `provider_id` | `""` | 留空＝跟随当前会话；也可以从下拉里选一个 TTS 提供商 |
| `test_text` | 「语音测试成功…」 | `/语音测试` 合成的那句话 |

**语音使用**

| 键 | 默认 | 说明 |
|---|---|---|
| `auto_enable` | `true` | 主动语音总开关（标记 + 随机） |
| `random_rate` | `15` | 只是随机分支的概率 |
| `voice_mode_rate` | `80` | 对方想用语音聊时随机分支的概率 |
| `auto_min_gap` | `600` | 平时两次主动语音的最小间隔（秒） |
| `voice_mode_min_gap` | `25` | 语音模式下两次主动语音的最小间隔（秒） |
| `auto_groups` | `[]` | 允许主动语音的群号，留空＝只在私聊 |

**用户偏好**

| 键 | 默认 | 说明 |
|---|---|---|
| `text_mode_ttl` | `1800` | 临时文字/语音偏好的有效期（秒） |

**长度与等待**

| 键 | 默认 | 说明 |
|---|---|---|
| `max_chars` | `50` | 主动语音字数上限 |
| `max_chars_user` | `2000` | 对方点名时的字数上限 |
| `auto_timeout` | `40` | 主动语音合成等待上限（秒） |
| `timeout` | `300` | 点名语音合成等待上限（秒） |
| `cooldown` | `0` | 任意两次语音之间的最小间隔（秒） |

**高级**

| 键 | 默认 | 说明 |
|---|---|---|
| `voice_markers` | `<语音>` 等 7 种 | 模型表示「这条用语音」的标记 |
| `force_keywords` | 7 个较窄的词 | 对方点名要语音；**不要**放裸 `voice` |
| `inject_prompt` | `true` | 是否往系统提示词注入交流方式规则 |
| `prompt_hint` | `""` | 自定义提示词，支持 `{marker}` `{max_chars}` |
| `strip_patterns` | 6 条正则 | 合成前删掉的内容 |
| `strip_markdown` | `true` | 顺带去掉 markdown 与代码块 |

从 2.1.0 升级时，`random_min_gap` / `random_groups` 会自动并入 `auto_min_gap` / `auto_groups`，
旧的 `voice` 关键词会被移除（它会误判「voice 是什么意思」）。迁移只跑一次。

## 按你自己的合成速度调参

语音不是瞬间生成的，`auto_timeout` 和 `max_chars` 要一起看。自建 qwen3-tts 实测（同一台机器）：

| 回复长度 | 合成用时 | 音频时长 |
|---|---|---|
| 10 字 | 11.3s | 2.6s |
| 24 字 | 17.5s | 5.0s |
| 42 字 | 64.4s（含一次重试） | 9.1s |

也就是说大约 **每字 0.5 秒，另外几秒固定开销，遇到重试会翻倍**。
按 40 秒预算，能稳定发出的差不多是 30 字以内——所以如果你的 TTS 也这么慢，
把 `max_chars` 调到 30 左右，比把 `auto_timeout` 拉到 70 更划算：
等太久才出声的语音，不如早点发文字。

先用 `/语音测试` 量一下你自己服务的耗时，再决定这两个值。

```powershell
python -m pytest tests -q
```
