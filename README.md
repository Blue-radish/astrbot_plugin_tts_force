<h1 align="center">念给你听（astrbot_plugin_tts_force）</h1>

<p align="center">让模型结合上下文挑选一句简短的话，用语音发给你。</p>

为 AstrBot 提供 `send_voice(text)` 工具。模型结合人设、上下文和用户要求，决定何时使用语音；
插件负责合成、校验和发送，支持私聊与群聊。

适合早晚问候、道谢、安慰等简短表达。技术长文、代码、链接和需要复制的信息优先保留文字。

## 安装与首次使用

1. 将仓库放入 AstrBot 的 `data/plugins/`，然后在 WebUI 重载。
2. 在「提供商」中配置一个 `text_to_speech` 类型的 TTS 提供商。
3. 关闭 AstrBot 自带的 TTS，即 `provider_tts_settings.enable = false`，避免重复朗读。
4. 在插件设置中选择语音提供商，留空则跟随当前会话。
5. 私聊机器人发送 `/语音测试`，验证语音服务与发送链路。

```bash
cd <AstrBot>/data/plugins
git clone https://github.com/Blue-radish/astrbot_plugin_tts_force
```

需要 AstrBot 4.28.1 或更新版本。运行依赖由 AstrBot 提供。

正常聊天还需要支持工具调用的模型，并在插件管理中启用 `send_voice`。
`/语音测试` 绕开模型，即使测试成功，也需要确认模型在正常聊天时实际调用了工具。

## 配置

在 WebUI 的插件设置中填写，共四项。

| 配置项 | 说明 | 默认 |
|---|---|---|
| `provider_id` | 语音提供商，留空跟随当前会话；指定后失效会返回配置错误 | 空 |
| `max_chars` | 单次语音字数上限，允许 10–300 字；超限拒绝，保留完整句子 | `30` |
| `timeout` | 单次合成等待上限，允许 5–600 秒 | `120` |
| `test_text` | `/语音测试` 朗读的内容，最多 200 字 | 「语音测试成功…」 |

字数和超时直接填写数字，超出允许范围时按边界取值。
合成耗时取决于服务、模型和文本长度，可先用短句测试，再调整上限。

AstrBot 的工具调用也有超时预算，配置项为 `agent_runner.config.misc.tool_call_timeout`。
如果希望插件先返回合成超时原因，请让插件的 `timeout` 比宿主预算小十几秒。
例如宿主预算为 120 秒时，插件可设为 100 秒。

## 日常怎么用

| 想做什么 | 示例 |
|---|---|
| 验证语音链路 | 发送 `/语音测试` |
| 明确要求语音 | 「这句念给我听」「用语音说句晚安」 |
| 自然聊天 | 模型根据上下文决定是否补一句简短语音 |
| 了解功能 | 「念给我听这个功能怎么用？」 |

例如，一轮聊天可能先解释事情，再发一句简短语音。

```text
用户：今天好累啊。
文字回复：辛苦了，早点躺下。
语音消息：早点休息，明天再说。
```

模型调用工具后，插件直接向当前会话发送独立语音消息。
成功时提示模型避免把同一句再用文字重复；失败时返回原因，由模型决定后续回复。
功能咨询适合用文字说明，是否调用仍由模型判断。

`/语音测试` 私聊可用，群聊仅管理员可用。正常语音工具支持私聊和群聊。

### 工具与返回结果

| 情况 | 返回给模型的信息 | 用户收到 |
|---|---|---|
| 成功 | 语音已发送，避免重复同一句 | 一条语音 |
| 超出字数上限 | 实际字数与配置上限 | 此次没有语音 |
| 上一条仍在合成 | 当前会话忙碌 | 此次没有语音 |
| 提供商、鉴权或网络异常 | 失败分类与脱敏原因 | 此次没有语音 |
| 音频不可用 | 文件为空、不存在或音频被截断等原因 | 此次没有语音 |
| 发送失败 | 发送错误原因 | 此次没有语音 |
| 发送超时 | 发送结果未确认，避免立即重试 | 可能已经收到 |

发送超时无法确定是否已经送达。立即重试可能重复发送，应先核实结果。

## 常见问题

### 一条语音都没收到

1. 先运行 `/语音测试`。失败时查看鉴权、接口地址、模型、音色或超时提示。
2. 测试通过但聊天时无语音，检查插件及 `send_voice` 是否启用、模型是否支持工具调用。
3. 查看这一轮是否真的调用工具，日志可搜索「语音已发送」。

### 同一句被念了两遍

检查 AstrBot 自带的 TTS 是否仍然开启。

### 从 2.x 升级

3.x 由模型调用工具决定何时发语音，配置精简为上述四项。
旧版的概率触发、回复标记转换、关键词识别、长期偏好记忆和自动改写机制已移除。
需要停用时，在插件管理中关闭插件。版本变更详见 [CHANGELOG](CHANGELOG.md)。

## 数据、隐私与覆盖范围

合成时会把朗读文本发送给所选 TTS 提供商。选择服务时请考虑会话内容与服务的数据处理方式。
语音投递到工具调用所在的会话，群聊使用时群成员可以听到。
错误原因会脱敏后返回模型。

## 已知限制

- 正常聊天的语音行为取决于模型是否调用工具。
- `/语音测试` 验证语音服务和发送链路，工具选择需要在正常聊天中另行验证。
- 超过字数上限时会拒绝发送，可让模型改成更简短的表达。
- 同会话的工具调用与语音测试共用执行流程，已有合成时会拒绝新请求。
- 宿主提前取消工具调用时，插件自身的超时提示可能无法返回。
- 不同 TTS 提供商的音频格式、质量和延迟存在差异。

## 开发

使用装有 AstrBot 和 pytest 的 Python 环境运行测试。测试使用伪事件与伪提供商。
仓库位于 AstrBot 目录外时，可通过 `ASTRBOT_ROOT` 指定宿主源码目录。

```bash
python -m pytest tests -q
```

更新图标时，在装有 Pillow 的开发环境中运行以下命令。

```bash
python scripts/sync_logo.py --source <原始透明PNG>
```

脚本生成根目录的 256×256 插件图标和 `docs/logo.png` 的 200×200 README 小图。
README 以 200px 显示。两张图使用同一设计，按用途保存不同尺寸。
